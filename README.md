**Noktalı Virgül**

Kahvem soğudu, ben hâlâ buradayım.<br>

Hafifledi omuzlarım, kalktı kederler.<br>
Yarın yine bir yenisi çıkar elbet,<br>
Ama bu gece uyusun hatalar, uyusun melekler.
